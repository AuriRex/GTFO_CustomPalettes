## Clothes Palette Material References

Materials used for the `MaterialOverride` property.  
Anything past material ID `17` seems to be identical to `17`.

|  ID  | Pattern / Details                        | Reflectivity | Interesting? |
|:----:|:-----------------------------------------|:------------:|:-------------|
| `0`  | Rough / Fabric like surface              |    🕯️Low    | ❌            |
| `1`  | Vertical stripes                         |    🕯️Low    | ✅            |
| `2`  | Very wrinkly clothes / not ironed        |    🕯️Low    | ❌            |
| `3`  | Even rougher / Fabric like surface       |    🕯️Low    | ❌            |
| `4`  | Like 3 but with diagonal stripes         |    🕯️Low    | ✅            |
| `5`  | Double diagonals / X pattern             |    🕯️Low    | ✅            |
| `6`  | Carbon fiber-esque pattern               |   ☀️High    | ✅📌          |
| `7`  | Denim-esque surface / diagonal stripes   |    🕯️Low    | ✅            |
| `8`  | Very coarse                              |    🕯️Low    | ❌            |
| `9`  | Very coarse, visual horizontal stripes   |    🕯️Low    | ❌            |
| `10` | Leather-esque surface                    | 💡Moderate  | ❌            |
| `11` | Larger bumps in the surface              |    🕯️Low    | ❌            |
| `12` | Minor surface bumps?                     |    🕯️Low    | ❌            |
| `13` | Minor surface bumps? Plastic?            |   ☀️High    | ❌            |
| `14` | Small scratch-like surface imperfections |    🕯️Low    | ❌            |
| `15` | Idk, looks identical to `13`             |   ☀️High    | ❌            |
| `16` | Diamond dot pattern                      |    🕯️Low    | ✅            |
| `17` | Similar to `13` and `15`                 |    🕯️Low    | ❌            |
